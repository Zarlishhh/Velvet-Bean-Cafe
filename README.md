Velvet Bean Cafe

A cozy, frontend multi-page restaurant and cafe website built using HTML, CSS and JS.

🔹Features

1. Multi-Page Navigation: Includes a Home page, dedicated Menu categories (Pizza, Pasta, Burgers, Beverages, Desserts), and a Checkout page.
2. Responsive Layout: Styled neatly using CSS Flexbox and grid systems to look clean across different screen sizes.
3. Custom Styling: Features a warm brown, cream, and soft gold color palette matching a modern cafe atmosphere.

🔹Technologies Used

1. HTML: For page structure and semantic markup.
2. CSS: For layout design, custom styling, hover effects, and typography.
3. JavaScript : For frontend logic, cart management, and interactive UI behaviors
